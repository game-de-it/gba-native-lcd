# GBA Native LCD シェーダー専用パッケージ

[English](README.md) | [日本語](README_JA.md)

このパッケージにはGLSLシェーダーだけが含まれます。RetroArch、mGBA、設定ファイル、
加速度センサー対応の専用APKは含まれません。

## 導入方法

1. すべてのファイルを、元のファイル名のまま同じディレクトリに置きます。
2. そのディレクトリをRetroArchのシェーダーブラウザーから見える場所へコピーします。
3. RetroArchのビデオドライバーを`gl`に設定し、RetroArchを再起動します。
4. **シェーダー > プリセットをロード**から`gba-reflective-v2.glslp`を選びます。
5. mGBAで240 x 160のGBA映像を使用します。960 x 640への正確な4倍表示が
   調整時の構成です。

プリセットには7つのシェーダー／LUTファイルがすべて必要です。`.glslp`だけを
移動したり、`rgb_curve_lut.png`の名前を変えたりすると読み込めません。

## KPA以外で正しく表示・動作しない可能性がある理由

本シェーダーはKONKR Pocket ADVANCE（Android model: GT78-VN）の実機
プロファイルであり、汎用LCDフィルターではありません。

- **解像度と倍率:** GBAの240 x 160の1ドットを、960 x 640出力の正確な
  4 x 4領域で表現する前提です。倍率が異なると、格子幅の不均一、モアレ、ちらつき、
  または想定より滑らかすぎる表示になる場合があります。
- **パネル固有の色:** 256段階RGB LUTはKPAの液晶で目視調整しています。別の
  液晶では色域、ガンマ、輝度、メーカーの色処理が異なるため、暗すぎたり赤や緑の
  色味が変わったりする可能性があります。
- **ピクセル単位の光源:** 画面端の影は960 x 640向けに30px／180pxで調整して
  いるため、別解像度では影の大きさが変わります。
- **傾き連動:** 標準RetroArchには専用APKが追加した`Accelerometer` uniformが
  ありません。その場合は固定光源へフォールバックし、傾きに応じた影と反射帯は
  動きません。
- **ビデオドライバー:** GLSL版なのでRetroArchの`gl`ドライバーが必要です。
  VulkanのSlang環境では、この`.glslp`を直接読み込めません。
- **性能:** 5-passと時間方向のフィードバックを使用します。GPU性能によっては、
  読み込めても処理速度が低下する可能性があります。

エラーなく描画できることは、シェーダー形式に互換性があることを示すだけです。
別端末でKPA向けに調整した見え方を再現できたことを意味するものではありません。
